# 🧠 MindVault AI

> **AI-powered learning platform that transforms academic documents into an intelligent knowledge base.**

MindVault AI is a application designed to help students organize, understand, and interact with their study materials using Artificial Intelligence.

Users can upload academic PDFs, automatically generate AI summaries, organize documents chronologically, and ask questions about their uploaded notes using Google's Gemini API.
